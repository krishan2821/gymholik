1. MongoDB Document Schemas

Every collection is partitioned by gymId to ensure multi-tenant security. Compound indexes ensure sub-millisecond query execution.

1.1 Collection: gyms

FieldTypeIndexDescription
_idObjectIdPrimaryUnique gym tenant ID.
gymNameStringTextRegistered gym title.
gymCodeStringUniqueCollision-free uppercase 6-10 char code (e.g. TITANF4067).
ownerIdObjectIdIndexedForeign key to users table for owner.
trialEndsAtISODateSparseTrial termination timestamp.
subscriptionActiveBooleanIndexedSubscription status flag.
settingsEmbedded-allowExpiredCheckin, maskPhone, reminderDays.

1.2 Collection: users

FieldTypeIndexDescription
_idObjectIdPrimaryUser identifier.
gymIdObjectIdCompound (gymId, phone)Tenant association.
phoneStringIndexedUnique credential for login.
passwordHashString-BCrypt salted password hash.
nameString-Full name of user.
roleStringIndexedOWNER, STAFF, TRAINER, SUPER_ADMIN.
statusStringIndexedACTIVE, PENDING_APPROVAL, SUSPENDED.
trainerTypeIdsArray[ObjectId]-Assigned specialization tags for trainers.

1.3 Collection: members

FieldTypeIndexDescription
_idObjectIdPrimaryMember ID.
gymIdObjectIdCompound (gymId, status)Tenant partition.
memberCodeStringCompound (gymId, memberCode)Auto-incremented gym member code.
nameStringCompound (gymId, name)Full member name.
phoneStringCompound (gymId, phone)Member contact mobile.
currentExpiryISODateIndexedActive membership end date.
currentDuePaiseLongIndexedPending dues in paise (1 INR = 100 paise).
statusStringIndexedACTIVE, EXPIRED.

1.4 Collection: payments

FieldTypeIndexDescription
_idObjectIdPrimaryPayment record identifier.
gymIdObjectIdCompound (gymId, createdAt)Tenant isolation.
memberIdObjectIdIndexedTarget member foreign key.
amountPaiseLong-Transacted sum in paise.
modeStringIndexedCASH, UPI, CARD, BANK_TRANSFER.
typeStringIndexedPAYMENT, REVERSAL.
collectedByObjectId-User ID of staff/owner recording entry.

1.5 Collection: attendance

FieldTypeIndexDescription
_idObjectIdPrimaryCheck-in log ID.
gymIdObjectIdCompound (gymId, checkInDate)Tenant isolation.
memberIdObjectIdIndexedChecked-in member ID.
checkInTimeISODateIndexedExact timestamp of access.
checkInDateString (YYYY-MM-DD)CompoundDate bucket for daily aggregations.
methodString-MANUAL, QR_SCAN.
