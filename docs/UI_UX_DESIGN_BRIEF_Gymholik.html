1. Brand Identity & Visual Philosophy

Gymholik embraces a modern Cyber-Emerald & Dark Sage design philosophy. The aesthetic reflects strength, premium discipline, high contrast, and focused utility. The interface minimizes eye fatigue during low-light gym hours while providing vibrant, state-of-the-art visual accents.

4. Component Architecture & Micro-Interactions

4.1 The Custom Floating Tab Bar

  • Geometry: Height 64px, pill border radius 32px, left/right margins 16px, bottom offset insets.bottom + 4px.
  • Background: Solid #0B2B26 (100% opaque) with 1px border rgba(218, 241, 222, 0.12).
  • Center Raised Check-in Button: 56px circular button lifted -18px above bar horizon. Features 3px solid #0B2B26 contour border. Active state features subtle pulse.
  • Sliding Sage Indicator: Spring-driven horizontal pill following active tab index with opacity transitions.

4.2 Micro-Interactions & Haptics

  • Button Presses: Spring scale compression to 0.96 with Haptics.impactAsync(Light).
  • Check-in Success: Sage screen pulse accompanied by Haptics.notificationAsync(Success).
  • Expired Warning: Double vibratory warning with warning banner modal.
  • Metric Counters: Smooth 650ms ease-out count-up animation on dashboard launch.

5. Accessibility Compliance (WCAG 2.1 AA)

  • All touch targets guarantee minimum 48x48 dp physical dimension.
  • Text contrast ratio against #051F20 canvas exceeds 7:1 for white and 4.8:1 for sage mint.
  • Full support for system reduceMotion setting (bypasses spring sequences for instant transitions).
