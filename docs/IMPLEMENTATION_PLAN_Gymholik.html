2. Quality Assurance & Testing Matrix

Backend Automated Testing
  • Unit Tests: JUnit 5 + Mockito covering payment calculation, membership expiry rules, and phone masking.
  • Integration Tests: Spring MockMvc tests verifying TenantIsolationIntegrationTest and TrainerAccessIntegrationTest.
Mobile Type & Route Testing
  • TypeScript Strict Mode: Zero compilation errors across all screens and components (npx tsc --noEmit).
  • Deep-Link Testing: Verified redirection across 3 accounts (Owner, Staff, Trainer).

3. Production Deployment & Monitoring Architecture

  1. Backend Deployment: Containerized via Docker, hosted on cloud container service behind Nginx reverse proxy with SSL termination and Let's Encrypt certificates.
  2. Database Cluster: MongoDB Atlas replica set with automated point-in-time recovery and compound index monitoring.
  3. Mobile Distribution:
    • Expo Application Services (EAS) building production binaries for iOS (TestFlight) and Android (Google Play Internal Track).
    • Sentry error tracking integrated for real-time mobile crash analysis.
